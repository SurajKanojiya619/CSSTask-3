# CSSTask-3

Hey there! This is my submission for the CSS Selectors assignment. The goal of this project was to practice targeting different HTML elements using proper CSS selectors, without relying on extra IDs, classes, or inline CSS where they weren't needed.

# What I Worked On
Connecting Files: Linked an external `style.css` sheet to `index.html`.
Styling Headings & Paragraphs: Used classes like `.head` and IDs like `#bglime` and `#para` to apply specific background and text colors.
Nested Words Styling: Styled specific words inside sentences (like "head" and "paragraph") using `<span>` tags.
Pseudo-classes (`:first-child`, `:last-child`, `:nth-child`): Applied different background and text colors to list items and links purely based on their position, completely avoiding extra classes or inline styles.

Folder Structure

 `index.html` — The main structure with headings, paragraphs, ordered lists, and unordered lists.
 `style.css` — Contains all the styling logic and selectors.

How to Run It

Just open `index.html` in any browser or use the Live Server extension in VS Code to see the output.
